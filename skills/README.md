# Skills

Agent skills that ship with Coqo, such as `coqo-review-default` (PLAN §7.8), for the native loop's skills loader (#62). One directory per skill.

`coqo-walkthrough` (PLAN §7.6) is in Coqo's Claude Code plugin, [`integrations/claude-code/coqo-plugin`](../integrations/claude-code/coqo-plugin/skills/coqo-walkthrough/SKILL.md), which Coqo loads into its Claude sessions. The native loop will load the same file.
